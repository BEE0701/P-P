## About

Bee Portfolio는 저를 소개하기 위해 제작한  
개인 포트폴리오 웹사이트입니다.

React 기반으로 반응형 UI,  
스크롤 애니메이션, SVG 심볼,  
프로젝트 링크, Contact 기능을 구현했습니다.

## Features
