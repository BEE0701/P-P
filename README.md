## About

Bee Portfolio는 저를 소개하기 위해 제작한 개인 포트폴리오 웹사이트입니다.  
React 기반으로 반응형 UI, 스크롤 애니메이션, SVG 심볼, 프로젝트 링크, Contact 기능을 구현했습니다.

## Features

| Feature | Description |
|---|---|
| 반응형 웹 | 모바일, 태블릿, 데스크탑에 맞춘 반응형 레이아웃 |
| 스크롤 애니메이션 | 섹션 진입 시 자연스럽게 등장하는 애니메이션 |
| SVG 심볼 | Bee 브랜딩에 맞춘 노드 심볼 사용 |
| 프로젝트 소개 | 실제 작업한 프로젝트와 배포 링크 연결 |
| Contact | 이메일로 바로 연결되는 Contact 버튼 |
