# 🐝 Bee Portfolio

작은 경험들을 모아 하나의 결과물로 완성하는  
웹 개발자 **Bee**입니다.

**Observe · Build · Improve**

---

## 📖 About

Bee Portfolio는 저를 소개하기 위해 제작한 개인 포트폴리오 웹사이트입니다.  
브랜딩, 디자인, 퍼블리싱, React 구현, 반응형 작업까지 직접 진행했습니다.

## ✨ Features

| Feature | Description |
|---|---|
| 반응형 웹 | 모바일, 태블릿, 데스크탑에 맞춘 레이아웃 |
| 스크롤 애니메이션 | 섹션 진입 시 자연스럽게 등장하는 효과 |
| SVG 심볼 | Bee 브랜딩에 맞춘 노드 심볼 사용 |
| 프로젝트 소개 | 실제 작업한 프로젝트와 배포 링크 연결 |
